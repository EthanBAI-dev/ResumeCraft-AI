# ResumeCraft 使用手册

当前免费版本无需注册。编辑与本地保存无需 AI Key，关注作者不是导出门槛。

## 第一次打开

进入 `/builder`，新浏览器自动载入虚构示例和男生示例照片；已有本地简历优先恢复。七步高亮引导可以跳过，之后从顶部「帮助」重播。

「载入示例」高亮表示示例已载入，首次点击仅收起提示。开始改内容也会取消高亮。再次载入会先确认：取消、替换当前简历（可撤销），或新建示例。不要为了看模板覆盖自己写好的内容，直接切模板即可。

## 功能在哪里

| 入口                            | 能做什么                                             |
| ------------------------------- | ---------------------------------------------------- |
| 内容 → 基本信息                 | 姓名、意向、联系方式、照片                           |
| 内容 → 工作/项目/教育等区块     | 编辑经历、增加条目、显隐和删除                       |
| 每个适用区块 → 字段排版 · 12 格 | 调整单条经历里的公司/日期等字段                      |
| 模板与样式                      | 六种模板、配色、字体、字号、行高、间距、页边距、栏宽 |
| 纸张预览 → 调整布局             | 拖动整个区块、查看虚线与十二格辅助线                 |
| 顶部 → 我的简历                 | 新建、复制、命名、切换、删除确认                     |
| 顶部 → 投递前检查               | 查看可解释的遗漏和格式提醒                           |
| 顶部 → AI 设置                  | 本次会话使用自己的 DeepSeek Key                      |
| 文件                            | JSON 导入/导出、Word、PNG 等                         |

窗口较窄时编辑器与纸张不并排显示，请用顶部「编辑内容 / 纸张预览」切换。

## 两种排版

**区块布局**决定工作经历、教育、技能放在哪一栏、哪一页。点击「调整布局」，拖动纸张六点手柄；键盘可 Tab 聚焦手柄、空格拾取、方向键移动、空格放下，Esc 取消。

**字段排版**决定一条经历中的公司、职位、日期如何分布。一行十二格，使用数字旁的 − / + 调宽；拖卡片换顺序；↵ 强制换行；另有左/中/右对齐和隐藏。放不下时自动换行，空内容与隐藏字段不占位置。同一区块的所有经历使用同一字段配置。

展开或修改字段排版，会自动打开纸张辅助线。外层虚线是区块，内层是字段，竖线是实际十二格。当前区块加深高亮；悬停字段查看格数和换行提示。模板原生抬头不是十二格布局时只显示真实边界，不虚构格数。辅助线不影响换行/分页，也不导出。点击「完成布局」隐藏。

行高随内容自然增长；文字行距在「模板与样式」设置。不要把占格宽度当成固定行高。

## 模板、照片和分页

切换模板保留文字，重新分配主栏/侧栏和样式，可撤销。字段的显式自定义配置会保留，所以自己改过抬头后，视觉上不一定与模板展示图完全相同。

照片设置只有一组男女示例选择和上传/移除操作，实际效果直接看简历。两种示例都是 AI 虚构人物，投递前替换或隐藏。

上传支持 JPG/PNG/WebP、最大 5 MB、最多 2500 万像素，在浏览器内缩至最大边 512px 并重新编码。纸张照片为 4:5 直角矩形、居中裁切，可调宽度；当前没有交互式裁剪编辑器。上传简历截图到“照片”不会识别文字，需要使用 [导入 Skill](import-skill.md)。

内容超出时按完整区块分页。单个区块比整页还高时会告警，不自动从区块中间拆开；可精简文字、降低字号/间距，或手动拆分内容。导出后仍要检查页底。

## 保存、备份和导入

每份简历保存在当前浏览器 IndexedDB。切换前先保存，切换后撤销历史重置。检测到多窗口冲突或存储错误时停止覆盖，请先导出备份再刷新。

- 定期「文件 → JSON」保存原生备份；备份含个人资料和照片，应妥善保管。
- 「文件 → 导入」接受 ResumeCraft 原生 JSON / 支持的 JSON Resume 字段，会新建一份，不替换当前稿。
- JSON Resume 第三方扩展不保证全部映射；保留原文件。原生 JSON 更适合完整备份。
- 换浏览器、域名、电脑或清理浏览器数据，不会自动搬运简历，需要导入备份。
- 本站没有账号同步、云端版本树或在线分享。

已有 PDF/Word/图片的用户可让 AI 助手使用 `resumecraft-import` 生成原生 JSON；网站不直接识别这些格式。

## AI：先对照，再采用

在「AI 设置」输入自己的 DeepSeek Key，再打开经历要点下「AI 润色 / 生成要点」。选择已有要点或描述真实经历，可附目标岗位/JD。对照文字差异、取消不想采用的条目，再确认采用。确认前原文不变，采用后可撤销；生成中原文改变时要求重新生成。

Key 只在页面内存，刷新清除。请求经本站后端转发官方接口，费用由你的模型账户承担；不支持任意代理。不要把 Key 放进简历、截图、Issue 或聊天消息。AI 结构正确不代表事实正确，不能直接采用虚构数字或被拔高的责任描述。当前为完整响应加加载状态，不是逐字流式。

## 导出前最后一步

「投递前检查」解释缺失信息、示例资料、日期逆序与长要点等问题，可核对最多二十个手动关键词。它不评招聘总分，不代表招聘系统或录用结果。

| 格式         | 注意事项                                                 |
| ------------ | -------------------------------------------------------- |
| PDF 系统打印 | 无 Worker 时可用；选择纸张、关闭浏览器页眉页脚，检查预览 |
| 高保真 PDF   | 需要 PDF Worker；回读提示不替代人工检查                  |
| Word         | 本地生成，独立排版，不保证与 HTML 模板相同               |
| PNG          | 需要 Worker，仅生成 PDF 首页                             |
| JSON         | 适合以后继续编辑，不是投递成品                           |

检查姓名、联系方式、头像、日期、页底和 AI 改写的事实后，再自行投递。
