# 免费、本地优先：多简历、示例体验与自带 AI Key

日期：2026-10-09

## 决策

按用户新的产品方向取消登录、收费与云端简历。以 IndexedDB 简历库替代单份草稿：新建、复制、重命名、切换和删除确认；JSON 导入不覆盖当前简历，改为新建条目。旧草稿迁移且保留旧记录。通过单条原子更新与修订检查阻止多窗口静默覆盖；保存失败保留内存内容、提示 JSON 备份。

严格业务 schema 会拒绝尚未输入完整的邮箱和空条目，不适合恢复草稿。本轮为编辑草稿保留结构校验、放宽未完成字符串字段，内容问题交给本地检查，而不是丢弃整份草稿。切换前保存、切换后重置历史并重挂载编辑表单，取消旧请求，避免 debounced 输入或旧 AI 结果串到另一份简历。

首次新用户加载示例及明确写着 DEMO 的虚构矢量头像；现有草稿优先恢复。已载入提示可关闭，内容编辑后取消高亮；再次载入有取消/替换/新建示例三种选择。上传照片在本机解码、最大边缩至 512px 后重编码，不接 OCR、不上传服务器。

AI 设置只保存页面内存中的 DeepSeek Key。每次请求传入独立凭据，限定官方地址，生产环境不回退站长 Key。限制请求体、跨站来源、单实例并发和哈希 Key 频率；明确这不是跨实例限流。原文与建议增加增删高亮，流式暂缓。

P5 不打总分，只列出有原因的检查项并定位区块，关键词由用户自己提取。避免用缺乏样本的评分暗示真实招聘结果。首页/帮助添加自愿 GitHub 关注与 Star，隐私页与部署说明同步，未部署线上服务。

## 验证

新增自动化覆盖旧草稿及不完整内容迁移、独立简历切换、重命名/删除、跨窗口冲突、损坏存储不覆盖、照片类型/大小、文字差异重建、规则检查、公开模式不退回站长密钥、跨站及超大请求拒绝。

浏览器脚本使用独立上下文：首次示例、高亮收起、取消/确认/撤销、新建切换及刷新、真实本地图片导入、移动端简历库、检查面板、模拟 BYOK 透传，以及 IndexedDB 无 Key / 刷新后 Key 清空。测试数据不接触用户原草稿。六套模板和七步引导另行回归。

最终结果：28 个测试文件、147 项测试通过，类型检查、lint 和生产构建通过。三套浏览器回归均通过，未记录页面异常。自带 Key 的真实 DeepSeek 润色请求返回 HTTP 200，保留原有“负责”责任级别；其他 Provider 未实测。检查 190 个 Git 可见文件未发现本机测试密钥。
