# 六套纸张模板与 AI 审阅流程

日期：2026-10-09

## 决策

沿用原有结构化内容与同源 CSS 渲染，模板由 3 套增至 6 套，没有引入外部模板服务。新增商务、刊物、北欧版式；模板卡片直接缩放真实 ResumeDocument，减少缩略图与最终排版不一致的可能。预设切换一次性写入布局、配色与字体，形成单次可撤销操作。

先使用已有结构化完整响应接口接通润色和经历生成，展示加载状态并提供取消。原文与建议分开显示，用户勾选后应用，支持拒绝、重新生成和撤销。尚未引入流式输出或词级 diff；这一版的目标是完成可审阅的内容更新流程。

单条润色只发送选定的要点；经历生成只发送用户输入，另附目标岗位与可选 JD。前端不接触 API Key。使用完整要点数组快照做应用前比较，生成期间有手动修改则拒绝覆盖。

## 踩坑

- 原双栏布局使用百分比宽度加 gap，主栏比例没有按扣除间距后的可用宽度分配。改用两列 minmax(0, fr) 后，长内容能在栏内换行。
- 引入模板缩略图后，页面有多个 .resume-root。原先全局选第一个根节点会把模板卡片当成导出内容；现在明确选取实际预览，并加入回归测试。
- 默认撤销节流会合并 500ms 内的操作，AI 接受建议需要独立的历史边界。新增应用操作在写入前后重置节流，防止快速接受多次建议或紧邻手动编辑时一起撤销。
- 小屏幕原先隐藏整个编辑面板。增加编辑/预览视图切换，并让打印样式去除界面和预览缩放。

## 验证

新增测试覆盖模板内容保留、导入区块 ID、建议采用/撤销、取消后的迟到响应、缺失配置、生成追加及冲突保护。浏览器回归覆盖六套模板、小屏幕、真实预览导出选择、打印样式与 AI 审阅。

在示例简历上，两套双栏为 1 页，四套单栏自动分页为 2 页。浏览器回归未记录到页面异常。AI 成功响应在测试中模拟，没有配置真实服务密钥，未验证真实 Provider 的生成质量和可用性。

## 续：引导、十二格恢复与 DeepSeek 联调

随后按用户反馈 fetch 了 GitHub：本地 HEAD 为 `e0f6873`，远端已有 `047c3c7`（atomic resume layouts）和 `0e0c219`（AI highlight diff review）两次更新。用户记得的十二格排版确实在 `047c3c7` 中。选择性移植 schema、字段布局 helper、编辑器和渲染器，保留本地六套模板及 AI 审阅，未引入远端 Sites 部署结构，未整体合并或推送远端。

新增「字段排版 · 12 格」折叠入口和醒目的「调整布局」按钮，分别负责内部字段与整个区块。修复上游重复字段过滤失效问题；旧数据缺少 itemLayouts 时使用默认值，未配置字段布局的基本信息继续使用各模板的专属头部。

新增七步首次引导和帮助对话框：原生 dialog 管理焦点与背景交互隔离，SVG 遮罩保留真实目标，高亮呼吸动画支持减少动态效果设置；引导结束恢复原视图，不写入简历或撤销历史，不触发 AI。提供桌面/手机浏览器回归脚本。

获得用户授权后，使用仅保存在被忽略的 `.env.local` 中的凭据实测 DeepSeek。首次请求因默认思考模式耗尽短输出预算而返回空结果；关闭思考模式后成功。联调还暴露了强动词建议与保真要求的冲突，调整提示词为保留责任限定、未提供结果时只写行动。最终润色与生成均 HTTP 200，耗时约 1.5 秒与 1.1 秒；示例正确保留“负责”“参与”“协助”，未补写修复或稳定性成果。这是小样本冒烟测试，不是普遍事实准确率保证。其他 Provider 未进行真实联调。

最终验证：24 个测试文件、136 项测试通过；typecheck、lint、生产构建全部通过。两个独立浏览器回归脚本通过，桌面 1440×1000 与手机 390×844 的引导高亮、帮助重播、焦点恢复、字段拖拽/调宽/显隐均正常，未记录页面异常。检查 169 个 Git 可见文件未发现本次凭据，`.env.local` 被忽略且权限为 600。
