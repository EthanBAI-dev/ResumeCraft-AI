## 决策

### DOCX 不追求像素级复刻

DOCX 的排版模型和浏览器 CSS 不同，硬凑两者会得到一个难维护、也不便于 HR 修改的文件。这里把 DOCX 定义为“内容可编辑出口”：语义层级、阅读顺序和 bullet 保持一致；PDF 才承担视觉保真。这个边界会在 UI 与 README 中明确标示。

### PDF 第一个版本使用浏览器打印

当前预览与打印同用 `ResumeDocument + globals.css`，浏览器打印不需要第二套渲染实现，立即可用。服务端 Chromium PDF 与文本回读必须一起完成，否则没有可靠字节流可校验；它们作为后续 P3 阶段，不把“window.print”包装成高保真服务端导出。
