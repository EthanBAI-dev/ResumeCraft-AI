## P4 · 可选 AI，而非站长承担模型费用

- DeepSeek Key 默认仅在当前页面内存中，刷新即清除，不写入简历或备份。
- 官方地址转发，每请求独立凭据，生产环境禁止退回站长 Key。
- 保留取消、原文冲突保护、勾选采用、撤销；增加中英文文字差异对照。
- 缺失事实列出待补充项，不把“参与/协助”自动拔高、不虚构数字。
- 完整响应优先，**逐字流式暂缓**；不能用假打字动画冒充流式。
- 后续可扩展其他 Provider、测试连接和更强限流，但不影响无 AI 编辑导出。

验收：无 Key 可编辑导出；无 Key 的公开 AI 请求被拒绝；Key 不进入 IndexedDB/JSON/日志；采用前简历不变，切换简历后旧建议不能写进新简历。

## P5 · 投递前检查，不叫招聘评分

- 核对姓名、联系方式、未替换的示例信息和头像。
- 检查可见条目标题、明确的日期逆序、过长要点和未填写描述。
- 每条提醒显示触发原因，并可回到对应区块。
- 可手动输入最多 20 个岗位关键词，仅检查文本出现情况，不判断能力或岗位匹配度。
- 不输出 0–100 分，不声称代表 ATS 通过率、行业标准或录用概率；没有量化数据不强制扣分。
- 规则明确且可单测；全部本机运行，无需数据集或 AI。

后续可按真实反馈补日期格式、链接和隐藏字段提示；暂不做语义匹配、模型评分或排名。

## P6 · 本地多简历，不做云端

- 自动迁移旧单份草稿，不覆盖原记录。
- 新建空白、复制、重命名、切换、删除确认；JSON 导入新建一份。
- 切换前保存，切换后重置撤销历史，避免跨简历撤销和旧 AI 建议串写。
- 允许保存填写到一半的内容；存储出错或检测到跨窗口修订冲突时停止覆盖并提示备份。
- 不做账号、云端数据库、公开分享、云端版本历史；以后需要时另行决定。

## P7 · 陌生人也能上手

- 新浏览器首次自动载入示例和明确标注的虚构头像；已有草稿优先恢复。
- “示例已载入”高亮可关闭，修改内容后消失；再次载入先确认，可取消或新建示例。
- 支持本地照片上传、男女示例选择、4:5 矩形照片、移除与尺寸调整；纸张内查看效果，不重复放大预览。
- 提供可分发的 `resumecraft-import` Skill、独立转换脚本、格式参考和兼容测试；不做网站内 OCR。
- README 展示六套真实渲染的完整 A4 页面、辅助线与导入流程图。
- 七步引导、模块帮助与隐私说明保持同步。
- GitHub 作者关注/Star 自愿，不设导出门槛。
- 保留 MIT License、贡献指南和 CI；上线配置见 [部署说明](deployment.md)。

尚需外部配置：选择适用的 Vercel 方案、绑定账户/仓库、配置平台限流、发布 Preview 并线上验收。引流用途是否符合 Hobby 非商业条款由实际用途决定，不保证永久免费。
